Overview

Purpose-built for archival workflows

The bot is operated from Discord commands, keeps a strict audit trail, and preserves the original phrasing of sources. It is designed for late medieval German and Latin administrative documents.

Knowledge hub powered

Controlled vocabularies, local person and place registries, and document type lists shape every analysis step. Historians can update the hub directly from Discord.

Transparent outputs

Every agent writes human-readable Markdown and machine-readable JSON. Researchers can review, edit, and integrate results into downstream pipelines.

Pipeline
Agent A

Text Recognition (HTR)

Uses Claude Vision with QA feedback loops to transcribe manuscripts while preserving original spelling and line breaks.

Agent B

Source Description

Classifies document types, extracts controlled keywords, and produces a formal description for archival records.

Agent C

Entity Extraction

Finds people, places, roles, and care actors, linking them to the Knowledge Hub and Wikidata when possible.

Agent D

Corpus Analysis

Builds statistics, topic summaries, social taxonomy patterns, and care analyses across the corpus with Voyant integration.

Agent E

Meta Monitoring

Tracks token usage, cost, storage growth, and recommends operational improvements to keep the system efficient.
